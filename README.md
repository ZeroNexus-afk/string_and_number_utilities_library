# String and Number Utilities Library 🛠️

![CI](https://github.com/ZeroNexus-afk/string_and_number_utilities_library/actions/workflows/ci.yml/badge.svg)
![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)

Một thư viện mã nguồn mở cung cấp các hàm tiện ích mạnh mẽ và dễ sử dụng để xử lý chuỗi (string) và số (number) trong Python. Được xây dựng tuân thủ nghiêm ngặt quy trình phát triển phần mềm mã nguồn mở.

## Tính năng nổi bật 
- **Number Utilities:** Kiểm tra số nguyên tố, tính giai thừa, kiểm tra chẵn lẻ, tìm UCLN, BCNN, dãy Fibonacci...
- **String Utilities:** Các tính năng xử lý và chuẩn hóa chuỗi.
- Tích hợp sẵn bộ Unit Test bao phủ toàn diện.
- Tự động hóa kiểm thử (CI/CD) bằng GitHub Actions.

## Hướng dẫn cài đặt 
1. Clone dự án về máy:
   git clone https://github.com/ZeroNexus-afk/string_and_number_utilities_library.git
2. Di chuyển vào thư mục dự án:
   cd string_and_number_utilities_library

## Hướng dẫn sử dụng 
from src.number_utils import is_prime, factorial

print(is_prime(7)) # Output: True
print(factorial(5)) # Output: 120
